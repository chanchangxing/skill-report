为什么热门

  • 社区驱动，持续更新
  • 覆盖全面，包含80+技术路线图
  • 交互式设计，点击节点可查看详细资源
  • 开源免费，支持本地开发和贡献

核心能力

  • 提供超过80种交互式技术技能路线图
  • 涵盖前端、后端、DevOps、AI、数据科学等热门方向
  • 集成最佳实践指南和技能测试题
  • 支持社区贡献，可通过 issue 或 PR 提交新路线图或修改
  • 通过可视化节点展示技能依赖关系和学习顺序

输入与输出

输入

  • 路线图定义文件（Markdown）
  • 社区贡献的建议或 issue
  • 本地开发时的环境变量配置（.env）

输出

  • 交互式路线图网页
  • 主题对应的学习资源链接集合
  • 最佳实践和测试题展示

两个使用场景

场景一

一名刚入门的前端开发者，感到学习内容杂多，通过访问项目网站选择“前端路线图”，按照交互式节点逐步学习 HTML、CSS、JavaScript 等技能，并点击节点查看推荐资源，系统化地构建自己的技能树。

场景二

一位团队技术负责人，希望为团队制定 DevOps 转型计划，参考了项目中的 DevOps 路线图和最佳实践，确定了需要掌握的 CI/CD、容器化、监控等关键技能，并向团队推荐该路线图作为学习参考。

具体运作流程

  1. 1

    访问 roadmap.sh 网站或克隆仓库本地运行

  2. 2

    从列表中选择感兴趣的路线图（如前端、后端）

  3. 3

    交互式路线图以节点图谱形式展示技能结构

  4. 4

    点击任意节点查看该主题的简要说明和学习资源链接

  5. 5

    用户可贡献内容：通过 issue 提交新路线图，或编辑 markdown 文件提交 PR

  6. 6

    开发者本地运行：克隆仓库，安装依赖，配置 .env 文件，执行 pnpm dev 启动开发服务器
