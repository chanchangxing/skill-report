为什么热门

  • Enhances PR/issue transparency by providing sanitized session logs
  • Helps reviewers understand agent decisions and prioritize PRs
  • Local-only approach avoids network and raw log uploads
  • Provides automated redaction of secrets and sensitive information

核心能力

  • Find likely local agent session logs based on query
  • Render sanitized transcript Markdown section
  • Generate local HTML previews
  • Append transcript to PR/issue body files
  • Create HTML previews for multiple PR/session candidates for audit

输入与输出

输入

  • Local agent session logs (JSONL files from Codex, Claude, Pi, OpenClaw)
  • PR/issue title, branch name, PR URL/number
  • Current working directory (cwd)
  • Original PR/issue body text

输出

  • Sanitized transcript Markdown (optionally appended to body)
  • Local HTML preview
  • Enriched PR/issue body file

具体运作流程

  1. 1

    Draft the normal PR/issue body first.

  2. 2

    Run `find` with title, branch, PR URL/number if known, and cwd to locate a high-confidence session.

  3. 3

    If found, ask user: 'Include a redacted agent transcript?'

  4. 4

    If user wants preview, run `preview`, open the HTML with `open`, and wait for confirmation.

  5. 5

    Before insertion, trim unrelated session turns based on scope (PR/issue title, branch, changed files, stated goal).

  6. 6

    If user approves, run `append-body` to add transcript to body file.

  7. 7

    Use the enriched body file for creation/update.

  8. 8

    If no safe session found or user declines, continue without transcript and do not add placeholder.

证据文件

限制与判断边界

  • Best effort: PR/issue creation continues even if no transcript found
  • Never uses network; only reads local logs
  • Never uploads raw logs; only renders sanitized Markdown
  • Fails closed on unresolved secrets, private keys, browser/session/cookie details, or auth URLs
  • Drops system/developer prompts, raw tool outputs, reasoning, env, cookies, tokens, and broad local paths
  • Keeps user prompts, assistant visible decisions, terse tool summaries, and test/proof outcomes
  • Removes unrelated session turns based on scope
  • Only adds transcript section when real transcript is found; no placeholder
  • Uses collapsed <details> section and updates existing markers
  • Always asks user before adding transcript to PR/issue body
  • Offers local HTML preview before insertion
