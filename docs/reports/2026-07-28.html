Dify 开源 LLM 应用开发平台

Dify 是一个开源的大语言模型（LLM）应用开发平台，通过直观的界面将 AI 工作流、RAG 流水线、智能体能力、模型管理和可观测性等功能集成在一起，帮助用户快速从原型开发过渡到生产部署。

为什么热门

  • 完全开源且功能全面，大幅降低 LLM 应用开发门槛
  • 支持数百种专有与开源模型，灵活集成多种推理服务
  • 提供可视化工作流和 Prompt IDE，显著提升开发效率
  • 社区活跃，拥有丰富的部署选项（Docker、Kubernetes、云平台等）

核心能力

  • Workflow：在可视化画布上构建和测试强大的 AI 工作流
  • Comprehensive model support：无缝集成数百种专有/开源 LLM，统一管理多种模型提供商
  • Prompt IDE：直观的提示词编辑界面，支持模型性能对比与辅助功能添加
  • RAG Pipeline：端到端的检索增强生成能力，从文档摄取到检索，内置 PDF、PPT 等格式解析
  • Agent capabilities：基于 LLM Function Calling 或 ReAct 定义智能体，支持 50+ 内置工具
  • LLMOps：监控和分析应用日志与性能，持续优化提示词、数据集和模型
  • Backend-as-a-Service：所有功能均提供 API，可轻松集成到业务逻辑中

输入与输出

输入

  • 用户通过聊天界面或 API 发送的消息
  • 上传的文档文件（PDF、PPT、Word 等）
  • 配置参数（模型选择、提示词、知识库设置）
  • 外部工具调用请求（如搜索引擎查询）

输出

  • LLM 生成的文本回复或摘要
  • 工作流执行结果（如数据分析报告）
  • 智能体工具调用的返回结果
  • API 格式的结构化响应

两个使用场景

场景一

企业内部知识库智能问答系统：企业将 PDF、PPT 等文档上传至 Dify，通过 RAG Pipeline 构建索引，员工通过聊天界面提问，系统利用 LLM 从知识库中检索并生成准确回答，大幅提升信息查找效率。

场景二

客户服务自动化机器人：电商公司使用 Dify 构建多渠道客服机器人，集成订单查询 API 和常见问题知识库，利用 Agent 能力自动处理退货、物流等问题，当遇到复杂问题时转人工，降低客服成本并提升响应速度。

具体运作流程

  1. 1

    使用 Docker Compose 部署 Dify 服务（运行 docker compose up -d）

  2. 2

    在浏览器中访问初始化页面，设置管理员账号并完成首次配置

  3. 3

    创建应用（如聊天助手或工作流），选择目标模型（如 GPT-4）

  4. 4

    通过 Prompt IDE 编辑提示词，定义应用行为和回复风格

  5. 5

    配置知识库：上传文档（PDF/PPT 等），进行向量化处理并建立索引

  6. 6

    添加工具（如 Google Search、DALL·E）和智能体逻辑（基于 ReAct 或 Function Calling）

  7. 7

    发布应用，获取 API 端点或嵌入代码

  8. 8

    在生产环境中通过日志和性能监控（LLMOps）持续优化应用

限制与判断边界

  • 部署需满足最低系统要求：CPU >= 2 核、RAM >= 4 GiB
  • 必须安装 Docker 和 Docker Compose v2.24.0 或更高版本
  • Dify Cloud 沙箱计划仅提供 200 次免费 GPT-4 调用，超出需付费
  • 部分高级功能（如企业级 SSO、审计）仅在 Dify 企业版中提供
  • 社区贡献的 Kubernetes Helm Charts 等部署方案可能需额外配置和测试
